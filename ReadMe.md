# 🎓 Student Management System – FastAPI

I developed a **Student Management System** using Python and FastAPI to make managing student information easier and more organized.

This project allows users to add new students, view their profiles, update their information, and delete records whenever needed. It also includes details such as attendance, academic marks, courses, and profile pictures.

While building this project, I got hands-on experience with FastAPI, Pydantic, and Jinja2 templates, along with understanding how CRUD operations work in a real-world application.

---

## ✨ Key Features

- **Add Students:** Register students by entering their name, age, gender, course, marks, attendance, and profile picture URL.
- **View Students:** Display all registered students in a clean, user-friendly dashboard with individual profile cards.
- **Update Details:** Easily edit student information whenever changes are required.
- **Delete Records:** Remove student details with a simple click.
- **Data Validation:** Use Pydantic to validate user inputs and maintain accurate student information.
- **Responsive Interface:** Provide a simple and organized interface for managing student records.

---

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **FastAPI** – Backend framework for building the application.
- **Uvicorn** – Server used to run the FastAPI application.
- **Pydantic** – For data validation and handling.
- **HTML5** – For structuring the frontend.
- **Tailwind CSS** – For styling and responsive design.
- **Jinja2** – For dynamically displaying student information.
- **Git & GitHub** – For version control and project management.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/gayathri8105/student-management.git
```

### 2. Navigate to the Project Folder

```bash
cd student-management
```

### 3. Install the Required Packages

```bash
pip install fastapi uvicorn jinja2 python-multipart
```

### 4. Run the Application

```bash
uvicorn main:app --reload
```

### 5. Open in Your Browser

Visit:

```text
http://127.0.0.1:8000
```
